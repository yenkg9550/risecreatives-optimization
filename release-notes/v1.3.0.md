# v1.3.0

> 前一版：v1.2.9

## 更新摘要

修正上傳限制誤擋外掛安裝、REST API 限制誤傷表單外掛、圖片尺寸與編輯器資源移除失效等問題；快取相關設定調整為更安全的預設；後台選單改名並重新排序；新增「版本資訊」頁與 GitHub Releases 更新檢查。

## 上傳限制

- 只限制媒體庫上傳：檔案類型與大小檢查僅套用於媒體庫頁面、編輯器媒體視窗與 REST `/wp/v2/media`。外掛／主題 ZIP 安裝、匯入器、備份還原等其他來源不再被擋。
- 新增過濾器 `risecreatives_skip_upload_check`，可讓個別站台針對特定外掛例外放行。
- `upload_size_limit` 不再套用於外掛／主題安裝頁與匯入頁。
- 媒體庫上傳新增伺服器端檔案大小檢查（原本僅影響上傳介面顯示）。
- 允許類型新增 avif、ico、txt、csv、xlsx、pptx；舊站設定自動補上新類型，不覆蓋原有選擇。
- 修正儲存設定時內容未變更會誤報「更新失敗」的問題。

## 效能設定

- 限制 REST API：預設放行 contact-form-7、wc/store、wpforms、fluentform、forminator、jetpack、oembed，可用過濾器 `risecreatives_rest_allowed_namespaces` 增減；設定頁說明同步更新。
- 停用預設圖片尺寸：不再改寫資料庫中的 thumbnail／medium／medium_large／large 尺寸設定；只過濾 WordPress 內建四種尺寸，保留主題、Elementor、WooCommerce 註冊的尺寸；舊版本誤將尺寸設為 0 的站，在功能關閉時自動還原為預設值（僅執行一次）。
- 系統資訊（PHP／WordPress 版本、記憶體限制、最大執行時間、上傳大小限制）移至「版本資訊」頁。

## 編輯器設定

- 「完全移除區塊編輯器資源」改掛在 admin_enqueue_scripts（原本掛在 admin_init 時尚未排入佇列，等於沒有作用）。
- 僅作用於文章編輯畫面，並不再移除 wp-components，避免影響 WooCommerce、Yoast 等後台頁面。

## 快取相關

- 「移除版本查詢參數（?ver=）」預設改為關閉。
- 開啟時只移除 WordPress 核心檔案的版本參數，保留主題、外掛、Elementor 的版本參數，避免更新後瀏覽器或 CDN 仍使用舊檔；如需全部移除可用過濾器 `risecreatives_remove_all_version_query`。
- 儲存「效能設定」「框架管理」「一般設定」「編輯器設定」後自動清除快取，支援 WP Rocket、LiteSpeed Cache、W3 Total Cache、WP Super Cache、WP Fastest Cache、SiteGround Optimizer、Autoptimize、Cache Enabler（未安裝者自動略過）；另提供 action `risecreatives_purge_caches` 供擴充。

## 後台選單

- 「效能監控」改名為「效能設定」。
- 子選單順序調整為：框架管理 → 上傳限制 → 一般設定 → 效能設定 → 編輯器設定 → 版本資訊。
- 點擊上層「展躍系統」會直接進入框架管理頁；「一般設定」頁面網址不變。

## 版本資訊與更新檢查（新增）

- 新增「展躍系統 → 版本資訊」：顯示目前版本、最新版本、發布日期、狀態、上次檢查時間與最新版更新說明，提供「立即檢查更新」與「立即更新」。
- 接入 WordPress 內建外掛更新機制，更新來源為 GitHub Releases：每 12 小時自動檢查（失敗時 1 小時內不重試）；「外掛」列表與「儀表板 → 更新」會顯示更新提示，可一鍵更新，也支援外掛自動更新開關。
- 更新來源可在版本資訊頁設定，或在 wp-config.php 定義 RISECREATIVES_GITHUB_REPO／RISECREATIVES_GITHUB_TOKEN（優先於後台設定）。
- 外掛檔頭新增 Update URI，避免被 WordPress.org 同名外掛誤判；只接受 GitHub https 下載網址；Token 只附加在本儲存庫的 GitHub 網址；Release 未附 ZIP 時自動修正資料夾名稱並驗證內容。
