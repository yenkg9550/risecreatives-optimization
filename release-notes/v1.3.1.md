# v1.3.1

> 前一版：v1.3.0

## 更新摘要

修正安全標頭（CSP）造成區塊編輯器內文區顯示「這項內容已遭到封鎖」的問題、改善 .htaccess 規則的同步與清除；同時正式提供後台選單改名與重新排序，以及新增「版本資訊」頁與 GitHub Releases 更新檢查。

> 說明：v1.3.0 的更新說明中提到的「選單改名／排序」與「版本資訊／更新檢查」，實際上是從本版開始才包含在外掛內（v1.3.0 的 ZIP 不含這些功能）。已安裝 v1.3.0 的網站需要先手動升級到 v1.3.1 一次，之後即可在後台直接檢查並更新。

## 安全標頭

- CSP 的 frame-src 加入 blob:。WordPress 區塊編輯器的內文區是以 blob: 網址載入的 iframe，原本的規則會把它擋掉（WordPress 7.x 起編輯器固定使用 iframe，問題更明顯）。
- 新增過濾器 `risecreatives_csp_directives`，可依個別站台調整 CSP。
- .htaccess 規則內容已是最新時不再嘗試寫入。
- .htaccess 沒有寫入權限、導致舊規則無法更新時，後台會顯示錯誤提示，並列出應手動改成的 CSP 內容。
- 停用與解除安裝外掛時，會一併移除 .htaccess 中的「RiseCreatives Security Headers」區塊，避免外掛停用後舊標頭仍然生效。

## 後台選單

- 「效能監控」改名為「效能設定」。
- 子選單順序調整為：框架管理 → 上傳限制 → 一般設定 → 效能設定 → 編輯器設定 → 版本資訊。
- 點擊上層「展躍系統」會直接進入框架管理頁；「一般設定」頁面網址不變。

## 版本資訊與更新檢查（新增）

- 新增「展躍系統 → 版本資訊」：顯示目前版本、最新版本、發布日期、狀態、上次檢查時間與最新版更新說明，提供「立即檢查更新」與「立即更新」。
- 接入 WordPress 內建外掛更新機制，更新來源為 GitHub Releases：每 12 小時自動檢查一次（失敗時 1 小時內不重試）；「外掛」列表與「儀表板 → 更新」會顯示更新提示，可一鍵更新，也支援外掛自動更新開關。
- 更新來源可在版本資訊頁設定，或在 wp-config.php 定義 RISECREATIVES_GITHUB_REPO／RISECREATIVES_GITHUB_TOKEN（優先於後台設定）。
- 外掛檔頭新增 Update URI，避免被 WordPress.org 同名外掛誤判；只接受 GitHub https 下載網址；Token 只附加在本儲存庫的 GitHub 網址；Release 未附 ZIP 時自動修正資料夾名稱並驗證內容。
- 系統資訊（PHP／WordPress 版本、記憶體限制、最大執行時間、上傳大小限制）從「效能設定」頁移至「版本資訊」頁。
- 解除安裝時一併清除更新相關設定與版本快取。

## 升級注意事項

- 升級後進入任一後台頁面，外掛會自動更新 .htaccess；若後台出現「無法更新 .htaccess」的提示，請依提示開放寫入權限或手動修改。
- 更新後請清除快取（WP Rocket 等），並在文章編輯頁按 Ctrl+Shift+R（Mac：Cmd+Shift+R）重新整理。
- 更新前建議先備份網站。
