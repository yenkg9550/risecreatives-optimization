# v1.3.2

> 前一版：v1.3.1

## 更新摘要

新增「備份管理」：可自動或手動備份網站，存放在本機、GitHub 或 Google Drive，並支援下載、刪除與還原。

## 備份管理（新增）

- 新增「展躍系統 → 備份管理」（位於「編輯器設定」與「版本資訊」之間）。
- 備份內容可自行勾選：資料庫、上傳檔案、外掛、主題、WordPress 核心（wp-admin、wp-includes、網站根目錄檔案與 wp-config.php，不含 wp-content），打包成單一 ZIP。
- 立即備份：按鈕在背景執行並顯示進度，可離開頁面；不依賴 WP-Cron。
- 自動備份：每天／每週／每月，可指定時間（網站時區）；本機保留份數可自訂，超過自動刪除。
- 存放位置：本機一律保存（wp-content 下隨機名稱並加上存取保護的資料夾）；可另外選擇上傳到 GitHub 或 Google Drive，各自設定保留份數。
  - GitHub：只允許私有儲存庫（公開儲存庫會被拒絕），以草稿 Release 的附件保存，單檔上限 2 GB；提供「測試連線」。
  - Google Drive：OAuth 授權（drive.file 範圍，只能存取外掛自己建立的檔案），支援大檔分段續傳；提供「測試連線」。授權畫面請設為「正式版」，否則授權 7 天後失效。
- 備份清單：可下載、刪除（含遠端副本）、還原；顯示每份備份的內容、大小與各存放位置的狀態。
- 還原：還原前會自動先備份目前的資料庫作為安全備份；只允許網址與資料表前綴相同的網站（不做跨站搬家）；不會覆蓋正在執行的本外掛與 wp-config.php。
- 備份檔不包含本外掛自己的設定（含 Token）與暫存快取。
- 解除安裝時會移除備份設定與排程，但已建立的備份檔會保留。
- 備份設定頁沒有「儲存設定」按鈕：勾選、下拉、數字與文字欄位只要有變更就會自動儲存，並在標題旁顯示儲存結果；設定不完整時（例如未填 Token 就勾選上傳到 GitHub）會提示並維持未啟用。
- 後台頁面按鈕改為加大並分色，hover 時維持原色略為加深。

## 升級注意事項

- 第一次使用備份功能請先按「立即備份」測試一次，並確認 PHP 已啟用 zip 擴充；要上傳到 GitHub 需啟用 cURL 擴充。
- 備份檔含有使用者密碼雜湊等敏感資料（勾選 WordPress 核心時還包含 wp-config.php），請妥善保管，雲端請使用私有儲存庫與開啟兩步驟驗證。
- 更新前建議先備份網站。
