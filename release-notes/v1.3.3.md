# v1.3.3

> 前一版：v1.3.2

## 更新摘要

備份可在途中暫停、繼續或取消；Google Drive 可備份到指定的資料夾；備份頁改用自訂對話框，後台日期統一為「年月日 時間」格式，版本更新來源預設為本儲存庫。

## 備份管理

### 暫停、繼續、取消（新增）

- 備份進行中，進度條下方會出現「暫停」與「取消備份」按鈕；暫停後按「繼續」即可接續進行。排程自動備份也可以從後台暫停或取消。
- 取消時會清除這次產生的暫存檔、未完成的 ZIP 與描述檔；若這次已上傳到 GitHub 或 Google Drive，該份遠端副本也會一併刪除。已有的舊備份不受影響。
- 按下後會在目前的小步驟完成後生效（通常 1～2 秒）；上傳到 GitHub 途中取消會直接中斷連線，暫停則會等該檔案上傳完畢。
- 還原（含還原前的安全備份）不提供暫停或取消，避免網站停在還原一半的狀態。
- 開始清理舊備份後就不能再取消，避免新舊備份都遺失。

### Google Drive 指定備份資料夾（新增）

- 「備份到 Google Drive」分頁新增「備份資料夾（選填）」欄位，可直接貼上資料夾網址（支援 `/drive/u/3/folders/…`、`?usp=sharing`、`open?id=…` 或資料夾 ID）。
- 留空則與先前相同，自動建立「RiseCreatives Backups - 網域」資料夾。
- 指定資料夾時需要完整的 Google Drive 權限（drive 範圍）；授權範圍不足時頁面會以橘色提示，按「重新授權」並在 Google 畫面勾選允許存取即可。
- 指定的資料夾不存在、已在垃圾桶，或授權帳號沒有編輯權限時，會顯示明確的錯誤，不會改放到其他位置。
- 「測試連線」會一併顯示備份資料夾名稱；支援共用雲端硬碟中的資料夾。
- 設定步驟說明改寫為 ①～⑥，並補充重新授權、權限範圍與「應用程式未經驗證」的說明。

### 介面

- 確認與通知改用自訂對話框，取代瀏覽器預設的 alert／confirm：字體加大，依情況以顏色區分（刪除／取消／錯誤為紅色、還原為橘色、完成為綠色），按鈕文字直接寫出動作（例如「刪除／保留」）。
- 還原確認改為勾選「我了解目前網站的內容會被覆蓋」後才能開始，取代原本的兩次確認。
- 設定自動儲存成功時不再顯示綠色「已自動儲存」文字，只在儲存失敗或有警告時提示。
- GitHub 與 Google Drive 設定改為分頁顯示。

## 其他

- 後台的日期時間統一為「2026年10月20日 10:47」格式（24 小時制），不再依 WordPress 一般設定的日期格式顯示；格式定義在主檔的 `RISECREATIVES_DATE_FORMAT`／`RISECREATIVES_DATETIME_FORMAT`。
- 版本更新的 GitHub 儲存庫預設為 `yenkg9550/risecreatives-optimization`：未設定或清空時自動使用，版本資訊頁的欄位會顯示預設值。已自行設定其他儲存庫或以 wp-config.php 常數設定的網站不受影響。

## 升級注意事項

- 要使用 Google Drive 指定資料夾的網站，升級後需要在備份頁貼上資料夾網址並按一次「重新授權」；授權時請選擇對該資料夾有編輯權限的 Google 帳號。
- 暫停時間不宜過長：部分主機會強制結束長時間執行的背景程序，超過 15 分鐘沒有進度會被判定為已中斷。
- 更新前建議先備份網站。
